# JARVIS Android — Offline Prototype 0.1

نسخة أولية مبنية على مشروع `jarvis-android.zip` الأصلي، مع إعادة تسمية الهوية إلى JARVIS وإضافة موجّه أوامر محلي باللهجة المصرية.

## ما الذي يعمل في هذه النسخة؟
- تنفيذ مجموعة أوامر محددة محليًا دون API أو إنترنت بعد تثبيت التطبيق وموديل التعرف الصوتي.
- فتح التطبيقات الشائعة (مثل WhatsApp وFacebook وInstagram وYouTube وChrome والكاميرا).
- فتح إعدادات النظام والواي فاي والبلوتوث والصوت والشاشة.
- تشغيل/إيقاف الكشاف وضبط مستوى الصوت.
- قراءة الإشعارات ومحتوى الشاشة (بعد منح الصلاحيات).
- أزرار Home وBack وفتح لوحة الإشعارات والإعدادات السريعة.
- إدخال الأوامر كتابةً أو بالصوت.

## ما الذي لم يُدمج بعد؟
**مهم:** هذه ليست بعد نسخة ذكاء اصطناعي توليدي محلي. لا يوجد حتى الآن نموذج Qwen أو llama.cpp مدمج داخل APK. الأوامر الحالية تعتمد على قواعد محددة، لذلك لا تفهم الأسئلة الحرة أو كل الصيغ الممكنة. دمج LLM محلي سيكون المرحلة التالية بعد التحقق من أن التطبيق الأساسي يبني ويعمل على الجهاز.

- نموذج محادثة محلي (مثل Qwen بصيغة GGUF عبر llama.cpp).
- ذاكرة دائمة للمحادثات باستخدام Room.
- تعرف صوتي مصري محسّن واكتشاف كلمة تنبيه موثوق.
- صوت مصري محلي مضمون دون اعتماد على حزمة TTS خارجية.

## المتطلبات والخصوصية
- لا يحتاج تنفيذ الأوامر المدعومة إلى API key أو اتصال بالإنترنت.
- تنزيل موديل Vosk من داخل التطبيق يحتاج الإنترنت مرة واحدة؛ بعد تنزيله يمكن استخدامه محليًا.
- نطق Android TTS يعتمد على الأصوات المثبتة على الهاتف؛ تأكد من تنزيل بيانات الصوت العربي مسبقًا لاستخدامه دون إنترنت.
- صلاحيات Accessibility والإشعارات والمايك اختيارية حسب الوظيفة التي تريد استخدامها. لا تمنح صلاحيات لا تحتاجها.
- المكالمات والرسائل ليست مفعلة في موجّه الأوامر المحلي الحالي.

## بناء APK بدون كمبيوتر باستخدام GitHub من الهاتف
هذا المشروع يحتوي على GitHub Actions لبناء APK سحابيًا. يلزم حساب GitHub واتصال إنترنت أثناء الرفع والبناء:
1. أنشئ مستودعًا جديدًا على GitHub من المتصفح واختر Public أو Private.
2. ارفع ملفات هذا المجلد إلى المستودع مع الحفاظ على المجلدات، خصوصًا `.github/workflows/build.yml`. يمكن استخدام GitHub Codespaces إن كان متاحًا لتسهيل رفع المجلد.
3. افتح تبويب **Actions** وشغّل **Build APK** أو ادفع commit جديدًا إلى `main`.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم `jarvis-apk`، ثم استخرج `app-debug.apk` وثبّته على الهاتف.

> لا يوجد APK جاهز مرفق بهذه الحزمة؛ يجب أن ينجح بناء GitHub Actions أولًا.

## أول تشغيل
1. افتح التطبيق وامنح إذن الميكروفون عند الحاجة.
2. اضغط زر تحميل Vosk مرة واحدة إذا أردت التعرف الصوتي المحلي.
3. اضبط Honor على السماح بالتشغيل في الخلفية إذا رغبت في تجربة الخدمة المستمرة؛ قد يظل النظام يوقفها بسبب إدارة الطاقة.
4. فعّل Accessibility فقط إذا أردت قراءة الشاشة أو تنفيذ ضغط/تمرير.
5. جرّب أولًا كتابة: `افتح واتساب` أو `شغل الكشاف` أو `افتح إعدادات الواي فاي`.
